## Purpose
This repository is a collaborative Git tutorial between a classmate an I where we created a branch, added files, commit, pushing to GitHub, and making a Pull Request (PR).

## Steps Followed
1. Created a local Git repository on my computer.
2. Added a collaborator on GitHub.
3. Created a new branch `Collab`.
4. Added a Python file `Tutorial.py`
5. Committed the new file with a message 
6. Pushed the branch to GitHub.
7. Created a Pull Request and assigned the collaborator as the reviewer.
8. Once approved, merged the `Collab` branch into the main branch.
